# Security Policy

Vismatix welcomes coordinated reports of security vulnerabilities in its hosted service, public integrations, and developer interfaces.

## Report a vulnerability

Email [security@vismatix.online](mailto:security@vismatix.online) with a concise description, affected public URL or component, impact, and safe reproduction steps. Do not include real customer data or credentials. Please avoid accessing, changing, or deleting data that is not yours, and avoid service disruption or social engineering.

The official disclosure contact is also published in the RFC 9116 file at <https://vismatix.online/.well-known/security.txt>. Vismatix’s public security information is at <https://vismatix.online/security>.

Please allow the Vismatix team reasonable time to investigate and coordinate a fix before public disclosure. This repository does not promise a response or remediation time. Do not send vulnerability reports to public issue trackers.

## Scope

This repository contains public integration documentation and client examples. Reports about the hosted Vismatix service should identify the affected production URL or API operation without including private data. For general account assistance, contact [support@vismatix.online](mailto:support@vismatix.online).
